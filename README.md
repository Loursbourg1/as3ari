# As3ari — أسعاري

**Community grocery price tracker and AI meal planner for Algeria**

As3ari (Arabic: أسعاري — "my prices") is a free, open-source progressive web app that lets Algerian families track real grocery prices reported by their community, compare costs across wilayas, and generate affordable, nutritious AI-powered meal plans based on today's market data.

---

## Features

| Feature | Description |
|---|---|
| 📊 **Price Feed** | Latest community-reported grocery prices, swipeable card UI |
| 🗺️ **Explore & Map** | Browse prices by wilaya with map view |
| 📈 **Trends** | Historical price charts per product |
| 🍽️ **AI Meal Planner** | Budget-aware weekly meal plans generated by Gemini AI |
| 📋 **Shopping Lists** | Auto-generated lists from meal plans with total cost estimates |
| ✏️ **Contribute** | Submit real price observations from any shop or market |
| 🌍 **Trilingual** | Full Arabic (RTL), French, and English support |
| 🔒 **Secure** | JWT auth, email verification, reCAPTCHA, strong CSP headers |

---

## Tech Stack

- **Frontend**: React 19 + TypeScript + Vite + Tailwind CSS
- **Backend**: Supabase (PostgreSQL + Auth + Edge Functions)
- **AI**: Google Gemini API via Vercel serverless proxy
- **Hosting**: Vercel (frontend) + Supabase (database + edge functions)
- **Testing**: Vitest

## Environment Variables

### Vercel (Frontend + API)

| Variable | Required | Description |
|---|---|---|
| `VITE_SUPABASE_URL` | ✅ | Your Supabase project URL |
| `VITE_SUPABASE_ANON_KEY` | ✅ | Supabase anonymous public key |
| `Gemini` | ✅ | Google Gemini API key (exact case) |
| `VITE_SUBMIT_VIA` | ❌ | `rpc` (default) or `edge` for report submission path |
| `VITE_REQUIRE_EMAIL_VERIFICATION` | ❌ | `true` to require verified email before contributing |
| `VITE_SHOW_DEMO_DATA` | ❌ | `false` to hide demo seed data in production |
| `VITE_MAP_TILE_URL` | ❌ | Custom tile server URL (defaults to OpenStreetMap) |

### Supabase Edge Functions (Secrets)

| Secret | Description |
|---|---|
| `ALLOWED_ORIGINS` | Comma-separated list of allowed CORS origins (e.g. `https://as3ari.vercel.app`) |
| `RECAPTCHA_SECRET_KEY` | Google reCAPTCHA v3 secret (optional, enables captcha verification) |
| `REQUIRE_EMAIL_VERIFICATION` | `true` to enforce email verification server-side |

## Local Development

```bash
# 1. Clone
git clone https://github.com/Loursbourg1/as3ari.git
cd as3ari

# 2. Install
npm install

# 3. Configure environment
cp .env.example .env.local
# Edit .env.local with your Supabase URL and anon key

# 4. Start dev server
npm run dev

# 5. Run tests
npm test

# 6. Type check
npm run typecheck
```

> [!NOTE]
> The app works in **demo mode** automatically when `VITE_SUPABASE_URL` is not set — no database needed to explore the UI.

## Database Setup

Apply Supabase migrations in order:

```bash
supabase db push
```

Or run migration files in `supabase/migrations/` manually via the Supabase Dashboard SQL editor.

## Security

- All price submissions validated with Zod on both client and server (edge function + DB function)
- No service-role key used in any edge function — all DB calls use the user's JWT
- Gemini API key never exposed to the client — proxied through a Vercel serverless function
- Origin allowlist enforced on all edge functions
- Strong CSP, HSTS, X-Frame-Options, and COEP headers configured in `vercel.json`
- No `console.log`, `debugger`, or secrets in any source file
